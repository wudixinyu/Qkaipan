## 编队页卡排左右滚动（CardFan）
需求：编队页顶部英雄卡陈列（8 张，内容宽 ~2066px > 陈列区 1320px，两端被窗口裁切）支持左右滚动浏览。

实现（纯脚本改动，场景无需重建）：
- `scripts/card_fan.gd`：新增滚动内核。`_scroll` 加在每张卡 base.x 上；范围 = [area.x - content_right, -content_left]（内容两端贴陈列区边缘），`scrollable()` = 区间宽 > 1px，装得下自动失效（主界面 4 卡不受影响）。
  - 拖拽：`_input` 里武装（按下点须在陈列区纵向条带内 **且** `gui_get_hovered_control()` 沿祖先能找到 CardFan，防止在筛选/排序弹层上拖动误滚），阈值 8px，松手按瞬时速度惯性滑行（GLIDE_RATIO 0.12）。
  - 滚轮：悬停条带上滚 = 朝队首，下滚 = 朝队尾，一格 260px，走 `_goto_scroll` 补间。
  - `focus_card(char_id, animate)`：把指定卡滚到中线（端点卡只能贴边）；拖拽中让路。
  - 注意 `make_input_local()` 返回基类 InputEvent，取 position 必须 `as InputEventMouse`，否则编译报错。
- `scripts/card_view.gd`：新增 `set_base_pos(pos)` + `_tween_moves_pos` 标记。hover 抬升/回落的补间目标是 `_base_pos`，滚动时不同步会把卡片拽回旧位置；set_base_pos 掐掉在飞的位置补间并按新基准对位。
- `scripts/formation.gd`：`_boot_ready` 门槛——进场 default_selected 不触发滚动（保留策划调好的初始版面）；之后 `_select()`（卡牌/卡库/棋盘点选）→ `focus_card` 动画回中，`_refresh_view()`（筛选/排序后）→ `focus_card(id, false)` 瞬时对位。

验证（全过）：
- 新增 `tools/smoke_fan_scroll.gd`（18 项：可滚判定 / 回中 / 钳制 / set_base_pos 同步 / 不可滚失效 / 滚轮路径）。**断言卡位时注意 per_index 缩放的视觉半宽（如 336×0.93×0.68/2≈106），且端点卡 focus = 贴边不是居中**，首轮因此误报 4 项。
- 新增 `tools/shot_formation_scroll.gd`：窗口化用 `get_root().push_input()` 注入悬停→按下→12 帧拖动→松手，抓 before/after 截图并断言滚动量 ≥50px。实测 _scroll 0 → -450.5（含惯性，滚到下限贴边），末卡炎骑烈士完整露出。
- 全量回归 317/252/216/140/151/114 全过，`--quit-after 120` 启动回归无错误；save.json 已备份/还原。
