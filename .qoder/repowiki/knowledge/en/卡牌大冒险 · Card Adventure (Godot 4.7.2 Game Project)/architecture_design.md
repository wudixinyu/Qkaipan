The root `project.godot` is the sole wiring point: it declares the main scene (`scenes/main_menu.tscn`) and registers six autoload singletons (`GameDB`, `SaveDB`, `RealmDB`, `StaminaSys`, `GachaSys`, `BattleCtx`) that form the cross-cutting contract all children share. Children communicate exclusively through these autoloads — `scenes/` loads UI via Godot's scene system, `game_scripts/` implements the autoload logic plus per-scene controllers, `assets/` supplies textures/fonts consumed by both, and `tools/` runs headless against the same autoload graph to build scenes, seed config, and smoke-test every subsystem. The three-tier data layer (read-only `GameDB` from `data/game_data.json`, persistent `SaveDB` on `user://save.json`, derived `RealmDB` in memory) is the boundary enforced at the project level; no child opens its own file for game state. Scene `.tscn` files are treated as generated output of `tools/build_*.gd`, so layout lives in the tools module while runtime behavior lives in `scripts/`.
