Each `.tscn` file is a self-contained Godot 4 scene graph rooted at a `Control` node that anchors to 1920×1080 and references its logic via an `ext_resource` script (e.g. `res://scripts/battle.gd`, `main_menu.gd`, `gacha.gd`). Visual assets — backgrounds, character sprites, icons, frames, and the shared `ui_font.tres` SystemFont — are declared as `ext_resource` entries so scenes stay asset-light. UI styling is centralized through dozens of `sub_resource StyleBoxFlat` definitions with consistent dark-purple palettes, gold accent borders, rounded corners, and drop shadows; these sub-resources are reused across Panels, Buttons, and Labels within each scene. The battle scene additionally defines layered rendering zones (`Background`, `CellLayer`, `UnitLayer`, `PlateLayer`, `FloatLayer`, `Overlay`) plus an `Overlay` subtree containing HUD panels (TopBar, TeamPanel, InfoPanel, LogPanel, StatusPanel, OrderStrip, ResultPanel) that together compose the turn-based combat view. Scenes are leaf assets consumed by the project's scene loader/manager rather than importing each other.
