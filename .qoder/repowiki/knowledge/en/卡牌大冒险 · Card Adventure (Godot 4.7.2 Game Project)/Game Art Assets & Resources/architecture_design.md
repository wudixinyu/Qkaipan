Flat asset tree under `assets/` organized by visual category: `art/characters/` holds per-character PNG sprites (with `.import` metadata for Godot's import pipeline), `art/bg/` stores background tiles, `art/frames/` contains rarity frame overlays; `icons/` groups SVG-based UI icons (element types, stats, screens) plus a `monsters/` subfolder of monster avatars; `fonts/ui_font.tres` is a Godot resource file referencing the UI font. Every raster image ships alongside a `.import` file so Godot can regenerate compressed variants, while vector SVGs are imported directly. There is no code in this module — it is purely data consumed by other modules via Godot's resource system.
